# FormNimora identity — Form cadence

**Concept:** three form rows create a cadence; the final row turns into an answer path, indicating completion and onward flow.

**Palette:** Cobalt `#2548D8`; vivid amber `#FFAD42`; white `#FFFFFF`.

The warm dot intentionally extends right and raises the final stroke; the asymmetric margins are part of the cadence/forward-motion cue.

**Primary master:** `formnimora-mark.svg` — two-color responsive/vector mark.
**Monochrome master:** `formnimora-mark-mono.svg` — one-color use; `currentColor` inherits foreground.
**Chrome icons:** `public/icons/formnimora-{16,32,48,128}.png`.
**Other generated variants:** `public/icons/formnimora-{black,white,mono-7254d6,square,app-icon}.svg`.

Use the 16/32 px icon only where the mark remains legible; prefer 32 px in compact surfaces. Keep clear space equal to one row-gap (about 1/4 mark height). Do not stretch, rotate, add shadows, or recolor the action dot independently. On dark fields use the white master; the primary mark includes no white knockouts.

The SVG mark is the editable source of truth. PNGs are generated Chrome raster assets. This is a project identity concept, not trademark clearance.
